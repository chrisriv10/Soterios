One workspace, a wider view

The whole PC,
in clearer focus.

Soterios brings security, privacy and system maintenance together. Each tool has a clear purpose, and the next step stays yours to choose.

Protection

Scan, review, then decide.

Run quick, full or custom ClamAV scans. Review detections in Quarantine, where you can restore a file, trust its hash, or remove it. Folder watching and removable-drive scan prompts are optional.

Soterios works alongside Microsoft Defender. It adds ClamAV scanning and selected Defender controls; it does not replace Windows Security.

System visibility

Understand what is running.

Inspect processes and their relationships, review persistence changes, and run Windows security audits covering settings such as Defender, UAC, Windows Update, BitLocker and Secure Boot.

Network security

See the connections and rules.

Review active connections, firewall rules and interface activity. Manage Windows VPN profiles and use connection alerts, blocklists and optional geolocation tools when they fit your setup.

VPN controls work with Windows profiles and your provider; Soterios is not a VPN service.

Maintenance

Make cleanup deliberate.

Find large and duplicate files, review disk and browser reports, schedule selected tools, and stage file cleanup in the Safety Vault before deletion.

Processes & system

Investigate a process.
Keep the context.

The Rust-backed Process Inspector gives you process details, relationships and risk signals, with familiar actions such as suspend, resume, adjust priority or inspect memory. Windows Audit groups key security settings with relevant management actions.

Optional VirusTotal reputation checks require explicit consent and your own API key. A lookup sends an executable SHA-256 hash; the file itself is not uploaded.

Firewall & connections

See the paths
your PC is using.

Inspect live connections and interface activity, review firewall rules, and use optional endpoint alerts and VPN controls. Geolocation can add approximate context to the map when enabled.

The network map uses ipwho.is for IP-location results. You can turn geolocation off in Settings or enable Privacy Mode.

Designed for local control

Private by default.
Clear when it connects.

Scanning, system audits, process monitoring, maintenance, password generation and strength analysis run on your PC. Soterios collects no analytics or telemetry and does not upload scan results.

Local work stays local

Reports, settings, history and quarantine records are stored on your machine.

Privacy Mode is yours

Privacy Mode disables the desktop app's breach, geolocation and reputation lookups, along with selected history and report features. ClamAV definitions, public IP lists and app updates remain separate.

Specific tools, specific data

When Soterios uses the network

Password & email breach checks

Have I Been Pwned receives only the first five hexadecimal characters of a locally calculated SHA-1 password hash. XposedOrNot receives the email address you submit when you run an email check.

Connection geolocation

When the map is used, IP addresses are sent to ipwho.is to resolve approximate locations. Turn the map off or use Privacy Mode to disable those lookups.

Process reputation

VirusTotal is optional. After explicit consent and API-key setup, a lookup sends the executable SHA-256 hash, not the file.

Browser extension services

The signed threat feed refreshes periodically and does not send visited URLs. Google Safe Browsing is optional; when enabled, it receives the checked URL and your API key.

Public lists, definitions & app updates

At startup, Soterios downloads public Spamhaus IP lists for local connection matching. ClamAV obtains definitions from its upstream service; packaged builds check for and can download app updates. These paths are separate from Privacy Mode.

The website itself uses no analytics, tracking scripts, third-party fonts or remote image services.

Browser extension

Protection for the open tab.

The Chromium extension checks password reuse locally, blocks ads and trackers with packaged rules, and uses a signed threat feed for phishing and malware indicators. Site-specific Google Safe Browsing checks can be enabled with your own key.

The extension has its own privacy setting and per-service controls.

Optional local assistant

Ollama stays on localhost.

Connect an Ollama model running on your own PC for system context and a limited set of on-request Soterios actions. Install and choose the model separately; the assistant is not a cloud service.

Soterios restricts this integration to a localhost Ollama endpoint.
