Security should help you understand your machine, not overwhelm you with noise. Soterios brings practical system-security capabilities together in one open-source project.

01 / Inspect

Malware scanning

Use ClamAV-powered scanning to help identify suspicious files, with reporting and quarantine-related workflows.

02 / Observe

Process inspection

Get a closer look at running processes and the activity you may need to investigate.

03 / Assess

System audits

Review security-related system settings and use audit tools to help assess your Windows environment.

04 / Control

Firewall controls

Access firewall-related controls designed to help you manage important system protections.

05 / Protect

Password strength

Use password-strength tools to help evaluate password choices before relying on them.

06 / Maintain

System maintenance

The Soterios approach
01—03 Principles, not promises

Your system.
Your visibility.
Your control.

Security software should make it easier to understand and manage your environment. Soterios takes a practical, local-first approach to bringing essential Windows security tools together in an open-source project.

01

Local-first by design

Built around working with your local system. Review the project's code and documentation to understand how each feature operates.

02

Open to inspection

Explore the source, understand the implementation, report issues, and contribute improvements through GitHub.

03

Practical, not performative

Useful security capabilities matter more than dramatic dashboards or claims that cannot be verified.
