Security and maintenance
for Windows.

Soterios combines file scanning, Windows security checks, network tools, and system maintenance in one application.

Malware scanning

Scan files with ClamAV.

Run quick, full, or custom scans. Review detections in Quarantine before restoring or deleting files. You can also trust a file hash so matching files are skipped in future scans. Folder monitoring and removable-drive scan prompts are optional.

ClamAV scans supplement Microsoft Defender. Soterios provides selected Defender controls and does not replace Windows Security.

System inspection

Inspect processes and Windows settings.

View running processes and their relationships, review persistence changes, and audit settings such as Defender, UAC, Windows Update, BitLocker, and Secure Boot.

Network security

Review connections and firewall rules.

Review active connections, interface activity, and Windows Firewall rules. Manage Windows VPN profiles and use connection alerts, IP blocklists, or optional geolocation.

VPN controls use profiles from your provider. Soterios does not provide a VPN service.

Maintenance

Find files and review cleanup.

Find large and duplicate files, review disk and browser reports, schedule maintenance tools, and stage files in Safety Vault before deleting them.

Monitor processes and network activity.

Review running processes, active connections, and Windows Firewall rules with dedicated tools.

Process Inspector

Inspect running processes.

View process details, parent and child relationships, signatures, hashes, and risk indicators. You can suspend or resume a process, change its priority, or inspect its memory. Windows Audit checks selected security settings and links to related controls.

VirusTotal checks are optional and require your API key and approval for each lookup. Soterios sends the executable's SHA-256 hash, not the file.

Network Monitor and Firewall

Monitor network activity.

Review active connections, interface activity, and Windows Firewall rules. Other tools provide endpoint alerts, VPN profile controls, and an optional connection map.

The map sends IP addresses to ipwho.is for approximate locations. Turn geolocation off in Settings or enable Privacy Mode to stop these requests.

Data stays local unless a feature needs a service.

File scans, audits, process monitoring, maintenance, password generation, and strength checks run on your PC. Soterios sends no analytics or product telemetry and does not upload scan results.

Stored on your PC

Settings, reports, history, and quarantined files are stored on your computer.

Privacy Mode

Privacy Mode turns off breach, geolocation, and process-reputation lookups, along with AI context, traffic and scan history, and automatic reports. ClamAV definitions, public IP lists, extension feed updates, and app updates are separate.

Online services and the data they receive

Password and email breach checks

Have I Been Pwned receives only the first five hexadecimal characters of a locally calculated SHA-1 password hash. XposedOrNot receives the email address you submit when you run an email check.

IP geolocation

When the map is used, IP addresses are sent to ipwho.is to resolve approximate locations. Turn the map off or use Privacy Mode to disable those lookups.

VirusTotal reputation checks

VirusTotal is optional. After explicit consent and API-key setup, a lookup sends the executable SHA-256 hash, not the file.

Browser extension checks

The extension downloads signed threat-feed updates without sending visited URLs. Google Safe Browsing is optional. If enabled, it receives the URL being checked and your API key.

Lists and updates

Soterios downloads public Spamhaus IP lists at startup and matches connections locally. ClamAV definitions are downloaded when you request an update. The browser extension downloads signed feed updates on a schedule. Packaged builds check for and can download app updates. Privacy Mode does not disable these downloads.

This website loads no analytics, tracking scripts, remote fonts, or third-party images.

Browser extension and local assistant.

The browser extension checks pages and blocks selected content. The optional Ollama integration connects to a model running on your PC.

Browser extension

Check links and reused passwords.

The Chromium extension checks password reuse locally, blocks ads and trackers with packaged filters, and checks pages against Soterios's signed threat feed. Google Safe Browsing checks are optional and require your API key. Google receives the URL being checked.

The extension has its own privacy setting and per-service controls.

Optional Ollama integration

Run a local model with Ollama.

Connect to Ollama on your PC to ask questions about a local system snapshot and request a limited set of Soterios actions. Install Ollama and download a model separately. Soterios connects only to localhost.
