Useful protection, with the network boundary in your hands.

Soterios records no analytics, product telemetry, tracking identifiers, or browsing history. Online protection services are separate: they contact named providers only after you confirm these choices.

Local password-reuse history was reset because the previous unkeyed format did not meet the new security standard. No plaintext passwords were stored.

Choose online protection services

Closing this page leaves every external request suspended. You can change each choice later.

Have I Been Pwned — Pwned Passwords

Endpoint: api.pwnedpasswords.com. Sends only the first five hexadecimal characters of a one-time SHA-1 password hash after a completed password field loses focus or you explicitly check it. It never receives the site or account name.

Soterios signed threat feed

Endpoint: chrisriv10.github.io. Downloads signed, hashed indicator shards every six hours—not when you visit a site. Sends no visited URL or domain.

Google Safe Browsing (advanced)

Endpoint: safebrowsing.googleapis.com. Disabled until you add your own API key in Settings. If enabled, Google receives the URL being checked and your key. Intended only for this free, non-revenue project.

Continuous or on demand

After confirmation, you may grant access to all HTTP and HTTPS sites so Soterios can identify password fields and show warnings automatically. If you decline, the extension keeps an on-demand “Protect this page” mode using temporary active-tab access.

What stays local

Only actual findings are kept, for 30 days. Incognito findings are never retained. Passwords, full URLs, SHA-1 values, HIBP prefixes, API keys, and unkeyed password hashes are never written to history or logs.
