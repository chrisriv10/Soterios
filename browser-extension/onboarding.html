Have I Been Pwned: Pwned Passwords

Endpoint: api.pwnedpasswords.com. This check uses k-anonymity. Soterios sends the first 5 characters of a SHA-1 password hash to Have I Been Pwned, then compares the returned suffixes locally. The password, account name, and page URL are not included in this request. The check runs when a password field loses focus or when you select “Check now”.

Soterios signed threat feed

Endpoint: chrisriv10.github.io/Soterios. The extension downloads signed, hashed indicators every six hours. Updates do not depend on the site you visit, and no visited URL or domain is sent.

Google Safe Browsing (advanced)

Endpoint: safebrowsing.googleapis.com. Disabled until you add your own API key in Settings. If enabled, Google receives the URL being checked and your key.

Automatic or on-demand page checks

You can grant access to HTTP and HTTPS sites so Soterios can detect password fields and show warnings automatically. Confirming also enables local ad and tracker blocking with packaged filter rules. If you decline, select “Check this page” in the popup to run a check with temporary active-tab access.

What stays local

Only actual findings are kept, for 30 days. Incognito findings are never retained. Passwords, full URLs, SHA-1 values, HIBP prefixes, API keys, and unkeyed password hashes are never written to history or logs.
