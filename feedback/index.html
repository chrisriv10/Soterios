Bug reports and feature requests are public GitHub issues. General feedback appears in public Discussions. You need a GitHub account to post. Review your message and attachments before submitting.

What to include in a bug report

Include:

  • Soterios version and Windows version/build
  • Steps to reproduce the problem
  • What you expected and what happened
  • Optional screenshots or relevant logs

Remove usernames, personal details, credentials, and private file paths before sharing. Soterios does not collect diagnostics automatically.

Report a security vulnerability privately.

Use GitHub Private Vulnerability Reporting and follow the process in our security policy. Do not post vulnerability details in public issues or Discussions.

A GitHub account is required. Include the affected version, reproduction steps, and potential impact if known. Do not attach credentials or unrelated personal information.
